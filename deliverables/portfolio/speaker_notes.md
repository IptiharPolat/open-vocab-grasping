# 《开放词汇感知驱动的机械臂抓取规划》讲解提示（约 6–7 分钟）

1. **封面（25 秒）**：先展示真正跑通的 seed-10 bottle 抓取。本项目在 PyBullet
   仿真中闭环了自然语言、视觉、抓取候选、规划和 Panda 执行；不把它包装成真机结果。
2. **问题与目标（40 秒）**：难点是让“抓哪个”与“怎么抓”同时正确。输入中文或英文
   指令，输出是安全的抓取抬升；验证边界是固定相机的桌面仿真。
3. **系统架构（55 秒）**：DeepSeek 只做受限高层计划，YOLO-World 提供语义，RGB-D
   与 GraspNet 给出几何候选，明确规则处理碰撞、工作空间、IK 和轨迹。
4. **开放词汇与三维关联（55 秒）**：展示真实检测图和候选投影图。实例 ID 只用于后验
   指标和物理评估，绝不替代开放词汇目标选择；深度一致性减少框内背景混入。
5. **6-DoF 抓取执行（55 秒）**：解释坐标变换和筛选链。神经候选不是直接执行；在真实
   bottle episode 中，1,009 个候选被筛成 4 个，最终抬升 0.115870 m。
6. **安全的 DeepSeek 规划（50 秒）**：模型只返回 JSON。系统检查 Schema、目标白名单
   和六步顺序，再编译固定 DSL 并 AST 白名单验证；没有任意 Python 或 shell 执行能力。
7. **正式实验（65 秒）**：40 个固定 seed、四类物体。检测 38/40、目标选择 37/40、IK
   35/40、端到端 26/40。DeepSeek 40/40 的计划层指标并不等同于物理抓取成功。
8. **失败与下一步（45 秒）**：14 次失败全部保留，其中未稳定抬升是主要问题。下一步是
   开放词汇分割、接触稳定性、闭环重抓和真实相机/机器人标定与安全控制。

总时长约 6 分 30 秒。所有数字、素材和完整来源已写入每页 PPT speaker notes。
