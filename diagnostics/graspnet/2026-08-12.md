## Reproduction

```bash
conda env create -f services/graspnet/environment.yml
conda activate ovg-graspnet
python services/graspnet/validate_official_example.py
cd third_party/graspnet-baseline/pointnet2
python setup.py build_ext --inplace
```

GPU completion requires a visible NVIDIA GPU/driver and a full CUDA development
toolkit with `nvcc`. The Conda `cudatoolkit` package alone supplies runtime
libraries and does not provide the required compiler.
